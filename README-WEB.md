# WayAnime Web (GitHub Pages)

هذه نسخة Web ثابتة من WayAnime، مبنية للنشر على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ Repository جديداً أو افتح المستودع المطلوب.
2. ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع (index.html و assets و fonts).
3. من Settings → Pages اختر Deploy from a branch.
4. اختر Branch: main والمجلد: /(root)، ثم Save.
5. افتح رابط GitHub Pages بعد اكتمال النشر.

## الوظائف
- استكشاف الأنمي والبحث والتصنيفات.
- الأكثر شعبية وأنميات الموسم.
- تفاصيل وتقييمات وتصنيفات ومقاطع دعائية رسمية عند توفرها.
- قائمة مفضلة محفوظة محلياً في المتصفح.
- تصميم متجاوب للهاتف والكمبيوتر.

## ملاحظات مهمة
- يعتمد جلب بيانات الأنمي على Jikan API (MyAnimeList). يلزم اتصال بالإنترنت وقد يفرض المصدر حدوداً مؤقتة للطلبات.
- GitHub Pages يستضيف الواجهة الأمامية فقط. وظائف تطبيق Electron الأصلية مثل تنزيل ملفات التورنت، FFmpeg، الحسابات والمزامنة تحتاج Backend منفصلاً؛ لم يتم الادعاء بأنها تعمل في هذه النسخة الثابتة.
- المقاطع الدعائية تُعرض من تضمينات YouTube الرسمية عند توفرها، ولا تستضيف هذه النسخة حلقات محمية بحقوق النشر.
